# GT Real - George Toscano Personal Brand Website

## Project Overview
A world-class personal brand website for George Toscano — a Bay Area realtor, Stanford technologist, and professional musician of 25+ years.

**Domain:** gtreal.io  
**Browser Title:** GT Real

## Brand Identity
- **Essence:** "Dedicated to every client. As if you were a patient."
- **Vibe:** Prada meets Madewell meets Bay Area soul - Luxury, Editorial, Warm, Trustworthy
- **Target Audience:** Bay Area homebuyers/sellers, real estate investors, first-time buyers

## Technical Stack
- **Frontend:** React with Tailwind CSS
- **Backend:** FastAPI (minimal, static site)
- **Animations:** Framer Motion
- **Icons:** Phosphor Icons
- **Fonts:** Cormorant Garamond (headings), DM Sans (body), Outfit (accents)

## Color Palette
- Cream: #FAF8F5 (Primary Background)
- Warm Grey: #E8E4DE (Secondary Background)
- Charcoal: #2C2C2C (Primary Text)
- Charcoal Light: #6B6560 (Secondary Text)
- Taupe: #9C8B7A (Accent)
- Dark Charcoal: #1E1E1E (Dark Sections)
